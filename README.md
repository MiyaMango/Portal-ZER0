Small game built in assembly for the Practice in Computer Organization discipline at ICMC-USP São Carlos. Built for the [ICMC achitecture](https://github.com/simoesusp/Processador-ICMC).
The goal of this project is to recreate some game mechanics from the Portal game series in a program written in assembly language.
